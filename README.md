# `re-fund`: Simple & Seamless Crowdfunding Contracts

A simple crowdfunding platform built on Ethereum where *builders* can propose
work, *funders* can finance this work, and *oracles* can evaluate and
authorize payment for this work.

## Quick Start

```
nvm use 24
npm install
```

## Tech Stack

- **Smart Contracts**: HardHatv3
- **Front-end**: React (via NextJS)
- **Back-end**: NextJS
